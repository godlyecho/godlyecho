# Источники

Дизайн и структура вдохновлены https://wivvi.net/ — XMB / PlayStation 3, Frutiger Aero и y2k.

Фото и ролик в галерее предоставлены владельцем страницы. Встроенные чёрные поля фото скрываются рамкой просмотра без изменения исходных файлов. Демо-медиа wivvi.net заменены личными материалами.

Иконки и термометр взяты из публичных ресурсов референса. Исходные сведения об авторах и лицензиях сохранены в REFERENCE_CREDITS.md.

Oxygen / KDE: https://invent.kde.org/frameworks/oxygen-icons — LGPL-3.0-or-later.
Шрифт — системный, устанавливаемый операционной системой; на устройствах Apple используется San Francisco. Файлы шрифтов не распространяются.

Ночной зимний видеофон и трек FRIENDLY THUG 52 NGG — Lost Angeles предоставлены владельцем страницы. Исходная аудиодорожка видео удалена. Музыка снижена на 28 dB, добавлено плавное начало и окончание.

Кнопка музыки: движок Liquid Glass for the Web — https://github.com/gentpan/liquidglass (MIT, lib/LIQUIDGLASS_LICENSE). Используется WebGL-рендер для живого видео, с CSS-запасным оформлением.
Варианты иконок: Lucide (ISC), Phosphor (MIT); лицензии в assets/icons/choices/. Цвет SVG адаптирован к белому.
Шрифт: локальный SF Pro Display Black 900, затем системный SF на Apple; на других платформах — системная замена с весом 900. Файлы Apple не распространяются.

Варианты шрифтов: Manrope, Oswald, Unbounded, IBM Plex Mono из https://github.com/google/fonts (SIL Open Font License 1.1). Файлы WOFF конвертированы из исходных TTF; поддержка кириллицы проверена. Лицензии и FONTLOG — assets/fonts/.

Аватарка Ильнара предоставлена владельцем страницы и добавлена без изменения изображения. Описание музыки обобщает последние открытые лайки профиля https://soundcloud.com/ilka-ytb/likes на момент заполнения.

Счётчик загрузок страницы — Hits (https://hits.sh, https://github.com/silentsoft/hits). Общее число ведёт внешний сервис; вкладки внутри страницы не увеличивают счётчик.
